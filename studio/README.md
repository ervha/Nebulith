# Nebulith Studio — Windowsアプリ

1008語の静的辞書、専用フォントv2.5、審査済み30例文をJARへ同梱するオフライン最小アプリです。

## 起動

配布用は **`build/dist/NebulithStudio.exe` 1ファイル**です。Windows x64向け、約92MB。Java・.NETランタイムの別途インストールは不要です。初回起動で同梱ランタイムを端末内に展開します。ネットワークや管理者権限は起動に使いません。

標準タイトルバーはありません。画面上部の空白・タイトルをドラッグして移動、ダブルクリックで最大化／復元。右上の最小化・最大化・閉じるボタン、外周6pxからのリサイズ、Alt+F4にも対応します。

`Start-Studio.cmd` は配布用exeがあればそれを起動します。JARだけをビルドした開発環境では、従来どおりJavaで起動できます。

```powershell
java -jar studio/build/NebulithStudio.jar
```

Java 8と21の両方でヘッドレス検証済み。通常の画面操作・IME・クリップボードは下記の実機確認が別途必要です。設定・下書き・お気に入り・閲覧履歴を端末内に保存します。同期・ネットワーク通信は実装していません。

## 操作

- 作業画面を「文章の相互変換」に切り替えると、日本語⇄Nebulithを左右の欄で自動変換します。完全オフラインの初版で、公式30例文と限定した文型に対応します。「対応文型」で範囲を確認できます。翻訳原文と方向は自動保存します。
- 訳文が確定した場合のみコピーと原文・訳文の入れ替えができます。未知語や未対応文を無視して一部だけ訳すことはしません。[対応範囲の説明](OFFLINE_TRANSLATION.md)を参照してください。
- 右上でライト／ダークを切り替え。選択語・入力・カーソルと選択範囲を保ちます。設定は次回起動時も維持します。`java -jar studio/build/NebulithStudio.jar --dark` でダーク起動もできます。
- `Ctrl+L` で検索欄へ移動、検索欄の `Esc` で検索語を消去。品詞チップはTabで移動しSpaceで選択できます。
- 筆記エディタのスライダーでプレビューを24〜64pxに調整。サイズと画面分割幅は次回起動時も復元します。
- 下書きは変更から約0.6秒後と正常終了時に自動保存。空の下書き・日本語・改行もそのまま復元します。OSの強制終了や電源断直前の未保存変更は保証しません。
- 語の詳細の「☆ お気に入り」で登録・解除。検索パネルの表示範囲を「お気に入り」にして一覧表示します。
- 語のクリック・キーボード選択を閲覧履歴として最新50件まで保持。「閲覧履歴」で一覧表示、「履歴を消去」で全消去できます。検索による自動選択は履歴に追加しません。
- 語幹・日本語・英語・IPA・ID・注記で検索。空白区切りはAND検索です。
- カテゴリーで絞り込み、選択した語のIPA・語義・注記・専用字体を表示。
- 「入力と表示」でNRS文字列を編集。原文を変更せずに別欄へ専用字体で表示します。未収録文字も入力欄に保持します。
- 選択した語の追加とコピーは、利用者がボタンを押した場合だけ行います。検索・カテゴリー変更で入力欄を書き換えません。
- 公式例文30件の本文・訳・審査メモを閲覧できます。

これは一般的な日英翻訳器ではありません。文字の表示を専用字体へ切り替えるもので、新しい文字コードへの置換は行いません。

## ビルド

```powershell
.\.venv-audit\Scripts\python.exe tools/build_studio.py
.\.venv-audit\Scripts\python.exe tools/verify_studio_bundle.py
.\.venv-audit\Scripts\python.exe tools/package_studio.py
```

既定ではインストール済みAndroid StudioのJDKとKotlinコンパイラを利用します。必要なら `--jdk <JDKフォルダ> --kotlin <kotlincフォルダ>` を指定します。JARビルドはダウンロードや環境変数の恒久変更を行いません。exeパッケージ作成は.NET 10 SDKを使い、初回に公式Temurin JREと.NETのビルド用パッケージを取得します。取得したJREはSHA256を照合し、ライセンス・告知と一緒に同梱します。ビルド時に辞書・例文・字体を正本から取り込み、古いバンドルを検出します。

`src/commonMain` はプラットフォーム非依存の検索モデル、`src/jvmMain` はJVMリソース読込とSwing画面です。Kotlin/JVMで機能を確認するPoCであり、KMP/Composeのビルド構成、Androidアプリ、システムIME、インストーラーは未実装です。共有コードを残して後段へ移せるよう分離しています。Windows向けの単一ポータブルexeは実装済みで、インストーラーウィザードとコード署名は未実施です。

`build/` は再生成できる配布物・検証ログの出力先です。JARを含む生成物をGit管理せず、ソースとバンドルの照合記録を残します。

## Windows実機で残る確認

1. 起動し、日本語・NRS・IPAで検索。0件、複数語、カテゴリー変更を確認。
2. Microsoft IMEの変換中・確定・再変換、選択範囲、改行の編集を確認。
3. 入力とプレビューの文字列が一致し、検索で入力が消えないことを確認。
4. コピーしたNRSを別アプリへ貼り付け、引用符・声門キャリア・改行を確認。
5. 100/150/200%の画面倍率と普段の文字サイズで字体・字間・折返しを確認。
6. ネットワークを切断した状態で起動・検索・例文表示を確認。
7. 入力中にテーマ切り替え、検索0件、Tab/Spaceの移動、プレビューサイズ変更を確認。ダークでカテゴリー選択・例文・選択色・スクロールバーも確認。

自動テストは実際のIME・OSクリップボード・人間の読み書き評価の代わりにはしません。

## 保存場所と配布検証

通常の保存先は `%LOCALAPPDATA%\NebulithStudio`。`studio.properties`にテーマ・文字サイズ・分割比率・下書き・お気に入りID・履歴IDを保存し、前回保存を`studio.properties.bak`に保持します。保存は一時ファイルから置き換えます。保存エラーは画面に表示し、読み込みに失敗した元ファイルは上書きしません。同じ保存先を使う二重起動を防ぎます。保存内容は端末内の通常のテキストです。

exeの展開先は同フォルダの`runtime/<同梱内容のSHA256>/`です。更新時も設定の保存先は共通です。.NETの単一ファイルホスト自身の展開キャッシュはWindowsの一時領域に作られます。exe本体だけを別フォルダへ移動・配布できますが、保存データはユーザーごとに保持します。

`build/package/package-manifest.json`にexe/JAR/ランタイムのハッシュ、公式出典、ビルド元、検証結果を記録します。JavaのないPATH、日本語と空白を含む作業フォルダから、生成exe自体を通して検証しました。JVM自己検証では設定・空/Unicode下書きの復元、お気に入り・履歴、破損ファイル保護、保存先ロックを確認。実ウィンドウの自己検証では標準タイトルバーなし、分割幅復元、最大化・復元・最小化・閉じるを確認しています。ドラッグと外周リサイズの細かな使い勝手、IME、OSクリップボード、高DPIの受入確認は別途必要です。
