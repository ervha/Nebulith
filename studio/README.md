# Nebulith Studio — Windows JVM PoC

1008語の静的辞書、専用フォントv2.5、審査済み30例文をJARへ同梱するオフライン最小アプリです。

## 起動

ビルド済みの環境では `Start-Studio.cmd` をダブルクリックするか、リポジトリルートで実行します。

```powershell
java -jar studio/build/NebulithStudio.jar
```

Java 8と21の両方でヘッドレス検証済み。通常の画面操作・IME・クリップボードは下記の実機確認が別途必要です。入力はメモリ上だけに保持し、終了すると失われます。保存・同期・ネットワーク通信は実装していません。

## 操作

- 語幹・日本語・英語・IPA・ID・注記で検索。空白区切りはAND検索です。
- カテゴリーで絞り込み、選択した語のIPA・語義・注記・専用字体を表示。
- 「入力と表示」でNRS文字列を編集。原文を変更せずに別欄へ専用字体で表示します。未収録文字も入力欄に保持します。
- 選択した語の追加とコピーは、利用者がボタンを押した場合だけ行います。検索・カテゴリー変更で入力欄を書き換えません。
- 公式例文30件の本文・訳・審査メモを閲覧できます。

これは一般的な日英翻訳器ではありません。文字の表示を専用字体へ切り替えるもので、新しい文字コードへの置換は行いません。

## ビルド

```powershell
.\.venv-audit\Scripts\python.exe tools/build_studio.py
.\.venv-audit\Scripts\python.exe tools/verify_studio_bundle.py
```

既定ではインストール済みAndroid StudioのJDKとKotlinコンパイラを利用します。必要なら `--jdk <JDKフォルダ> --kotlin <kotlincフォルダ>` を指定します。ダウンロードや環境変数の恒久変更は行いません。ビルド時に辞書・例文・字体を正本から取り込み、古いバンドルを検出します。

`src/commonMain` はプラットフォーム非依存の検索モデル、`src/jvmMain` はJVMリソース読込とSwing画面です。Kotlin/JVMで機能を確認するPoCであり、KMP/Composeのビルド構成、Androidアプリ、システムIME、インストーラーは未実装です。共有コードを残して後段へ移せるよう分離しています。

`build/` は再生成できる配布物・検証ログの出力先です。JARを含む生成物をGit管理せず、ソースとバンドルの照合記録を残します。

## Windows実機で残る確認

1. 起動し、日本語・NRS・IPAで検索。0件、複数語、カテゴリー変更を確認。
2. Microsoft IMEの変換中・確定・再変換、選択範囲、改行の編集を確認。
3. 入力とプレビューの文字列が一致し、検索で入力が消えないことを確認。
4. コピーしたNRSを別アプリへ貼り付け、引用符・声門キャリア・改行を確認。
5. 100/150/200%の画面倍率と普段の文字サイズで字体・字間・折返しを確認。
6. ネットワークを切断した状態で起動・検索・例文表示を確認。

自動テストは実際のIME・OSクリップボード・人間の読み書き評価の代わりにはしません。
