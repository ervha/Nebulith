# Nebulith（ネビュリス / 星辰語）

> **「天球の運行と共鳴する、静謐なる星辰の筆記言語」**

Nebulith（ネビュリス）は、天体運行論・軌道力学および自然言語の心地よい音韻美学（シャレイア語・キプソル語等を参考）に基づいて構築された架空言語（Conlang）体系、およびそのタイポグラフィ・ツールキットです。
地球言語（英語、ラテン語、ロマンス諸語等）の安易な借用・既視感を徹底排除した純粋な独自体系を備えています。

## ✦ 音韻体系 & 公式転写規則（NRS: Nebulith Romanization System）

### 1. 母音（Vowels）
* **6単母音**:
  * `a` [a]（開前舌母音・天球の開口）
  * `e` [e]（半狭前舌母音・星風の流線）
  * `i` [i]（狭前舌母音・北極星の光芒）
  * `o` [o]（半狭後舌円唇母音・満ちる月環）
  * `u` [u]（狭後舌円唇母音・深き天底）
  * `y` [y]（狭前舌円唇母音・第六の星辰母音）
* **4公転二重母音**: `ai` [ai], `ei` [ei], `au` [au], `oi` [oi]

### 2. 16主星子音 + 1原初軸キャリア
* **流音・鼻音（余韻）**: `m, n, l, r`
* **摩擦音（星気）**: `s, z, c [ʃ], j [ʒ]`
* **唇音・気音**: `f, v, h, w`
* **破裂音（天体の会合）**: `p, t, k, b, d, g`
* **原初軸キャリア**: `'` [ʔ]（母音の頭音キャリア・音節分離）

### 3. 音節構造と「柔剛調和」の音韻美学
* **音節骨格**: `(C)V(C)`
* **無標ソノリティ（流麗な基調）**:
  * 開音節（母音終わり）および高い響き度を持つ流音・鼻音・歯擦音 **`l, r, n, m, s`** を基調とし、星辰の滑らかな運行と心地よい余韻を創出。
* **有標ソノリティ（破裂音・摩擦音の機能的活用）**:
  * 硬質性・瞬発性・確固たる概念（`suf` 計算, `tor` しかし, `kiv` ビット, `jyt` 結節, `krap` 昆虫, `jylot` 盟約, `torp` 衝突 等）において破裂音・摩擦音の語末（Coda）を有機的に共存させ、語感の豊かなコントラストを実現。

## ✦ 3次元方向副詞体系

英語の "westward" や "to the west" に相当する、一語による総合的方向副詞および分析的格表現を完備。

* **総合的方向副詞（語幹 ＋ `-u`）**:
  * `kymdenu`（西へ、日没の方角へ）
  * `faldenu`（東へ、日の出の方角へ）
  * `novdenu`（北へ、天頂極へ）
  * `tuldenu`（南へ、天底極へ）
  * `vorasu`（前へ、先方へ、未来へ）
  * `pasonu`（後ろへ、背後へ、過去へ）
  * `lerinu`（左へ、左舷へ）
  * `parinu`（右へ、右舷へ）
  * `celosu`（上へ、天頂へ、上方に向かって）
  * `talosu`（下へ、大地へ、下方に向かって）
  * `silinu`（内へ、内部へ、心の内へ）
  * `folanu`（外へ、外部へ、外界へ）
* **分析的向格表現（`to` ＋ 名詞句）**:
  * `to kymden`（西へ向かって）
  * `to celos`（上空に向かって）
