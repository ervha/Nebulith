# Web版 開発チェックポイント 2026-10-15

## 実装範囲

今回の対象は開発計画1〜5の共通基盤と初回拡充。正本語幹・正本述語フレーム・過去の監査承認は変更しない。

- 翻訳原文・方向・文ごとの解釈、文字サイズ、閲覧履歴を保存・復元（原文欄は左右均等固定）。候補の確定は復元後に再確認。
- 旧Web保存キーから単一プロファイルへ移行。保存不可・容量不足・破損・他タブ競合を表示。原データ保持、一括バックアップ、検証後の一括復元。
- 未対応JSONの複数取込・内容確認・統合。再取込の二重加算防止、元要求と回数の保持、言語・解釈別の集約、原因分類・状態変更・再出力。
- 文単位の補完・語義・所有範囲の選択と確定。主語未指定の述語文では自然な日本語慣習に合わせて「私（el mi）」を自動補完（明示指定時はそちらを優先）。原文が一意で未変更の文は編集後も解釈を保持。変更・重複した文では解釈を再確認。
- 既存語の動詞49見出し（初回25＋第2弾24）を追加。計102見出し・104述語・動詞表層形1,992。辞書内の未整備動詞は95→46。新しい正本語幹は追加していない。
- 述語・格役割・時制・否定・相・モダリティ・補完・語句対応を共通の意味データへ集約。
- 主語を明示した2節の条件・理由（ので／から／だから）・譲歩（けれど／けれども）・時間（とき）を合成。主語や時制は引き継がない。入れ子や未対応の節では完成訳を出さない。
- 「〜すること」「〜することだ」を行為句（動名詞句）または指針叙述として変換。主節未入力の文末「〜から」「〜だから」「〜ので」を理由節ドラフト（Zen ...）として先行提示。
- 「動作の解釈」を「見る（観測する／仰ぎ見る／展望する／予見する）」「話す（話す／語り合う／告げる／ささやく／問う）」「行く（歩く／走る／行進する／滑空する／迂回する）」「思う（信じる／思索する／決断する／尊ぶ）」の各群へ拡充。UIの選択肢を文脈に応じて動的提示。
- 追加8語・追加項構造の審査台帳を作成。語義の区別と未審査事項、参照データのSHA-256を記録。
