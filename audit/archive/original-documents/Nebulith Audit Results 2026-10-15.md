## 4. 6段階の実施結果と所見

### Phase 1：予備的データ整合性

4形式全てUTF-8 BOMなし、CRLFで統一され、ファイル内の改行混在なし。全件のID昇順・フィールドの一致を確認。対象のファイル別ハッシュ・行数は `evidence.json: manifest` に保存した。

**F-01：カテゴリー集計の50語計上漏れ（追加所見、Major相当）。**
JSONの `categories` の `wordsCount` 合計は **958**。カテゴリー12の名称がメタデータでは `12. 食・飲料・調理・食器`、実際の50レコードでは `12. 食・飲料・調理・食具` と異なる。前者の件数が0になり、Markdownの概況表も0語と表示される。一方、本文と4形式のレコードには50語が実在する。レコードは4形式で等しくてもメタデータが正しいとは限らない。

再監査条件：カテゴリーIDを安定キーにし、全レコードが既知のカテゴリーへ一意に所属すること、実数・JSONメタデータ・Markdown概況表の語数が一致し、総和が1,008であること。

### Phase 2：静的音韻・正書法

指定の `comprehensive_audit_1008.py` を実行し、補足検査で全件を独立集計した。禁止文字・語根重複・IPA重複は0件。

**F-02：IPA表記と転写規則の不一致（追加所見、Major相当）。**
IPAは `[...]` が957語、`/.../` が51語。手順書Phase 2の `/.../` 形式という指定には統一されていない。さらに仕様 §2.2 の `c → ʃ`, `j → ʒ` に対し、必要な対応記号を欠く語が**82件**。例：ID 3 `celmon [cel.mon]`、ID 93 `jylkat [jyl.kat]`、ID 477 `cynor [ʒy.nor]`、ID 590 `celporv /selporv/`。82件はこの特定の検査で検出した数であり、全ての発音誤りの総数ではない。

IPA表記の一意性がPassでも、音価の妥当性を保証しない。再監査では括弧方式を決定し、NRS→音素列の変換と辞書IPAを全件比較する。

既存スクリプトは `io` を含む `bion*` 10語と短語の距離1ペア4組も報告した。ただし母音連続が別音節なら二重母音の禁止に直結しないため、10語を自動的に不適合とはしていない。短語の類似も禁止基準がないため参考所見とする。

### Phase 3：多言語衝突・偽同源語

既存検出器は候補0件。しかし内容を確認すると、収録は**86概念・463語形（重複を含む）**であり、約2,000語ではない。英語意味欄への概念キーワード一致で対象になったのは **171/1008レコード**、残り837件は未照合。語形に言語ラベル・出典・版がなく、6言語の対象範囲も保証できない。収録には `honey: hachi`、`animal: d動物` 等の要確認データもある。

既存判定は短い比較語の距離2を一般には拾わず、部分一致も距離条件付きである。補足検査では、同じ収録リストに対して手順書どおり **距離≤2 または部分一致**を適用し、1,010組の比較から **1候補**を検出した。

**F-03 / CHK-04：ID 245 `ser`（hand）と日本語 `te`（手）は距離2。**
両語が手を意味する対応は明確で、手順書の機械的な閾値には不適合。これをもって実際の借用や語源関係を認定するものではない。偶然一致の除外条件は未定義なので、監査中に独自の免除を設定していない。

再監査条件：言語・概念ID・正規化方法・出典・版を持つ比較集合を固定し、語彙全体の意味対応を確認、全候補の裁定を記録する。現在の候補1件を直すだけでは全面合格にはできない。

### Phase 4：語根ファミリー・形態

上位は `tal*` 71、`vel*` 41、`dar*` 40、`fal*` 33、`ner*` 30、`val*` 30、`mar*` 24、`jyl*` 22語。最大集中度は両方の閾値を満たす。

**F-04 / CHK-08：語末の例外規定が確定していない。**
基本5子音以外で終わる子音末語は159件（一覧は `marked_codas`）。母音末を除いて評価すると、基本5子音末は770/929＝82.88%。母音末を許容して全語を分母にした場合は84.23%。いずれも例外未適用の参考値であり、実際の準拠率とは断定しない。

仕様 §2.1 は語末を5子音に「厳密に限定」、監査基準は堅固・瞬発概念への例外を許容しており一致しない。`torp`（天体衝突）等は例外候補だが、`poryk`（距離）、`kymhav`（極夜）、`darnyv`（朝露）等を含め159件に承認済みの分類がない。最低95%を証明できないため保留。

方向専用副詞は14/14で語幹実在と `-u` を確認：`celosu, faldenu, folanu, kymdenu, lerinu, novasu, novdenu, parinu, pasonu, silinu, talosu, tuldenu, tulosu, vorasu`。一般副詞や名詞兼副詞、通信の `forward` を意味する動詞はこの専用派生集合と区別した。

母音交替や同化形の存在は見られるが、必須適用条件・許容結果・語源の基準集合がなく「正しく配置された」とする全件認証はできない。CHK-07の数値合格を意味的一貫性の合格へ拡張しない。

### Phase 5：フォント・OpenType・描画

既存TTFをそのままfontToolsでロードし全テーブルを展開した。生成スクリプトは実行していない。`head, hhea, maxp, OS/2, hmtx, cmap, loca, glyf, name, post` の10テーブルが存在。65グリフ・64マップ文字、cmap format 4、EM=1000を確認。

`fonts/font_b64.txt` と、`fonts/preview.html`, `tools/num_specimen.html` に埋め込まれたBase64は、いずれも既存TTFとバイト単位で一致。指定2ページをブラウザで開き、`document.fonts.ready` 後のFontFace状態 `loaded` と `document.fonts.check` のtrueを確認。追加標本で64文字すべてと`.notdef`を描画・視認した。空白の非描画は意図した挙動。

**F-05 / CHK-12：脱ラテン化のゼロ件基準が客観的に適用できない。**
特に `U/u`, `J/j` 等には既存文字の骨格を連想する形が見られる。比較対象、どの程度の共通骨格を残存と数えるか、約物・空白・`.notdef`の扱い、評価者間の一致基準がない。全件標本は保存したが、「65グリフ全ての残存0」を認定せず保留とする。

**F-06：版表示の不一致（追加所見、Minor相当）。**
監査手順書のFont v2.1に対し、プレビュー見出しはv2.0、TTFのname ID 3は `Nebulith-Regular-v1.0`、ID 5は `Version 1.0`。解析時に `'created' timestamp seems very low; regarding as unix timestamp` の警告も出た。バイナリが読めることと版情報・日時の正しさは別に管理する。

### Phase 6：相関詞・軌道相・規範コーパス

36セルは全て `hi/ta/va/ka/sen/ni` と `te/as/uo/hav/ku/zen` の組み合わせどおり。ただし、36語はいずれも1,008件の辞書には未登録。CHK-10は「定義充足率」のためPassとし、語幹総数に機能語も含むかという範囲の未決定を追加所見とする。

**F-07 / CHK-11：活用規則と適用例が不十分。**
`-ast/-in/-ol/-cor`、`re-/co-` の宣言と例はあるが、以下が未解決：

- `kiran → kirol` は単純な `-ol` 付加でなく `an` 脱落を伴う。その一般的条件は定義されていない。
- 同じ `kiran` が仕様 §2.3 ではエンジニア、§6.2 では書くという例に現れる。辞書では「（コードを）記述する、紡ぐ、組む」であり、行為者として用いる例と一致しない。
- `-ast` が厳密な5子音末限定と衝突する。文法的派生に例外を適用するか未定義。
- 受動態の例 `Refalun el govan ia de falun en vyr.` は `ia de` が連続し、対格の名詞句がない。受動化に伴う項構造の規則が不明。
- 双数 `vyr + el → vyrel` と、辞書の `vyrel`（観測する、ID 953）が同形。これは語根重複とは別の文法的曖昧性で、解消条件がない。

**F-08 / CHK-15：3篇の規範コーパスが辞書・文法・訳に整合しない。**
全3篇（対話は3発話）から69トークンを抽出。内訳は辞書直接一致23、定義済み機能語27、相関詞4、辞書語幹からの単純派生候補5、未解決10。派生候補は文字列上の解析可能性であり、品詞・意味・統語の正しさを自動認定しない。

| 星辰箴言 | `sentis` が未登録で、全称事物として定義された `sente` とも異なる。`korol` は辞書語幹・規定された派生規則から解決できない |
| 天文台の日誌 | `rekorval` は不明。辞書の `corval` は名詞で、綴りも `re + corval` とは異なる。名詞の `corval` を平衡化する動詞として扱う根拠がない。`cel mon` は各語未登録で、暗黒星雲として辞書にある語は `celmon`（ID 3） |

## 5. 是正の順序と再監査条件

監査依頼に対し、問題を隠す語形置換や辞書の再生成は行わず、是正候補と再確認条件を記録する。

1. **Criticalを解消（F-03、F-05）**：比較辞書の出典・意味対応・距離条件を固定しCHK-04を再実施。フォントの比較基準と評価手続きを決めてCHK-12を裁定。語形変更に進む前に、偶然一致をどのように扱うかを言語設計の判断として確定する。
2. **原データの品質を是正（F-01、F-02）**：カテゴリー名称・IDと件数、IPA転写を確定し、4形式を同期。現行の全件一致を維持しながら、メタデータおよび音価の正しさも検証する。
3. **文法の適用可能性を確立（F-04、F-07）**：語末制限の対象（語根/活用語/機能語）、承認済み例外、完了相の縮約、受動の項構造、代名詞・指示詞、同形語の解決規則を定義する。
4. **規範コーパスを再校訂（F-08）**：全語を辞書または定義された機能語・派生規則に結び付け、逐語解析と和訳を再確認。辞書登録のために語数を増やす場合、1,008語固定という監査基準を別途版管理する。
5. **版情報を同期（F-06）**：TTFのname情報、プレビュー、仕様の版を一致させ、再生成後のバイナリとBase64を再比較する。
6. 是正後は別の日付または実行IDで証跡を保存して15項目を再監査する。本回の不適合・保留記録を後続の合格結果で上書きしない。
