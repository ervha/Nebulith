原本巻『灰環の灯を継ぐ者たち』では、写字生ユラと灯守セヴが、焼け残った帳面と失われた頁を追う。都市の外へ持ち出された言葉を取り戻す過程を、三つの別巻が異なる視点から補う。全4巻24章。

旧版の学習索引500語、正本用例30件は資料篇に残した。語彙索引は既存Web辞書の1,463項目へ広げた。旧ファイル名 `Codex_Astrolith_Canon_Scripture.html/.pdf` はリンク互換用に同じ合本を置き、画面や本文では新書名を用いる。

## 出典原本としての扱い

本書を、今回作成した物語と各語の物語用例の引用元となる編集原本として明記した。現実に存在した古代史料や、言語の歴史的語源を証明する資料と称するものではない。

現在の辞書にある1,463項目すべてを、日本語の物語へNebulithの語を織り込む用例として掲載した。各語の物語用例は語義を引用しつつ、記録官・舟守・採集師・灯守の視点で綴る。出典番号は `VL-00001` のように安定した語IDと結び付け、巻名・章・HTMLアンカーを持つ。

**物語用例は日本語であり、Nebulith全文の対訳ではない。** 確認済みのNRS文法例は既存の30件を別に保持する。新しい物語文を翻訳エンジンの完全一致対訳へ登録しない。保留中の創発候補1,020件はこの辞書範囲に含めず、拡張語の文学的掲載によって既存の審査状態も変えない。

## 更新と追補

```powershell
.\.venv-audit\Scripts\python.exe -m pip install -r tools/requirements-print.txt
.\.venv-audit\Scripts\python.exe tools/build_publications.py
.\.venv-audit\Scripts\python.exe tools/verify_web_bundle.py
```

この一つの生成手順で、物語台帳・原本HTML/PDF・三別巻HTML/PDF・語の出典対応・Webの原本ビュー・単語詳細の引用を更新する。

- `data/literary_sourcebook.json`：編集原本データ。人物・場所・各章本文・各語の引用・出典番号を保持。既存の引用を手で推敲しても、次の生成で書き戻さない。
- `tools/literary_sourcebook.py`：初期の物語設定と新規用例の編集規則。新しい辞書語は各巻の第6章へ追補し、既存の用例・章割り・IDは動かさない。
- 既存語の意味・品詞・ID・分類が変われば、保存した依存ハッシュとの不一致で生成を止める。該当する物語用例を再確認してから更新する。自動的に旧用例を承認し直す処理はしない。
- 辞書から外れた語の記録は `retiredEntries` に保持する。現行版の網羅率には加算しない。
- 書籍更新前にWebだけを生成して新しい語が欠けていれば、エラーで知らせる。原本とWebの不一致を黙って配布しない。

Webの「物語の中で」は引用・書名・巻・章・番号を表示し、「原本を読む」から同じ引用へ移動する。ファイルで開く単一HTML版には引用と出典を内包し、同梱されていない原本へのリンクは表示しない。
