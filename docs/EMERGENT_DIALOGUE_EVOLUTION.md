# Nebulith 自律的言語進化・対話創発システム仕様書 (Emergent Dialogue Evolution Architecture)

## 1. 概要と目的

本システムは、2体のAIエージェントに **Nebulith の既存語彙・文法体系で対話** を行わせ、対話の中で生じる「表現の不足（Communicative Need）」を契機に **新しい語彙を自律的に造語・合意形成・辞書昇格** させるフレームワークです。

天文学や星石工学といった **「専門的シチュエーション」** だけでなく、食事・道案内・買い物・体調の気遣いといった **「汎用的・日常的な会話シチュエーション」** を主軸に含めることで、生きた生活言語としてのバランスと表現力を全方位に発達させます。

---

## 2. デュアル・シチュエーション・マトリクス（汎用 × 専門）

語彙が専門用語に偏ることを防ぐため、シミュレーションは以下の **2大領域（比率 2:1 以上で汎用日常を優先）** で構成されます。

### A. 汎用的・日常会話シチュエーション（Universal / Everyday Life）
1. **食事・料理・喫茶（`UNIV-01`）**:
   - **役割**: 料理人 × 旅人
   - **創発される概念**: 湯気・水蒸気（`darsul`）、朝餉・軽食（`novbion`）、くつろぐ・一息つく（`sirtul`）
2. **旅・街歩き・道案内（`UNIV-02`）**:
   - **役割**: 街の訪問者 × 住人
   - **創発される概念**: 近道・抜け道（`pelnel`）、目印・ランドマーク（`pelsel`）、曲がり角・辻（`peltor`）
3. **市場・買い物・品定め（`UNIV-03`）**:
   - **役割**: 買い手 × 職人店主
   - **創発される概念**: 手触り・肌触り（`palvas`）、肌馴染みの良い・しなやかな（`zenmol`）、手頃に譲る・商う（`keltan`）
4. **体調・感情・友人へのいたわり（`UNIV-04`）**:
   - **役割**: 夜更けまで働く書記 × 気遣う友人
   - **創発される概念**: 身体のこわばり・凝り（`morkym`）、眠気・あくび（`tymsul`）、労わる・気遣う（`mersul`）

### B. 専門・星辰文明シチュエーション（Specialized / Astral Lore）
5. **天体観測・光学力学（`SPEC-01`）**:
   - **役割**: 天測士（Vyreler） × 律暦師（Sufor）
   - **創発される概念**: 屈折光環・二重光条（`faljyl`）、軌道演算する（`vyrkels`）
6. **星石工芸・結晶共鳴学（`SPEC-02`）**:
   - **役割**: 光符工匠（Kiranor） × 光学調律師
   - **創発される概念**: 光曇り・波長濁り（`falmor`）、光調律する・再清澄化する（`falzenor`）

---

## 3. 自律進化パイプライン（3段階フィルタリング）

1. **Proposal（造語提案）**:
   - 話し手エージェントが、既存の語根合成または派生接尾辞（`-as`, `-ik`, `-om`, `-or`, `-ul`, `-el` 等）を用いて `*新語` を文脈内で提案。
2. **Grounding & Reuse（対話内合意）**:
   - 聞き手エージェントがその文脈を解釈し、応答ターンで同じ単語を再利用（Reuse）することで意味的合意が成立。
3. **Arbiter Validation（言語評議会エンジンによる自動審査）**:
   - **音素配列検査**: 母音核の有無、3連続子音の禁止、無標識語末子音（`l, r, n, m, s`）の優遇スコア計算。
   - **完全衝突ゼロ検査**: 正本1,008語および拡張語彙との語根重複・日本語グロス重複が `0` であることを検証。
   - **自動昇格**: 合意スコア `>= 0.85` かつ衝突ゼロの単語を `data/translation_extensions.json` と `data/extended_corpus_v2.json` へ自動統合。

## 4. 実行方法と検証コマンド

# 2. Web Studio データバンドルの再ビルド
python tools/build_web_studio.py

# 3. 創発語彙および全スプリント整合性テストの実行
node tests/verify_emergent_dialogue.js
node tests/verify_sprint3_lexicon_and_adverbs.js
node tests/verify_sprint5_derivation_and_aspects.js
