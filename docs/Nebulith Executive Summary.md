# 人工言語「Nebulith（ネビュリス）」プロジェクト 全体計画・設計総括マスターリファレンス

**最終更新日**: 2026-10-14

**対象バージョン**: 要件定義・設計仕様書 v17.0 / マスター辞書データ v12.0（新音韻体系へ刷新・再構築中）

**ターゲット環境**: **Windows 10/11 (Desktop JVM)** ＆ **Android (アプリ本体)** [単一統合スタジオアプリ]

**利用スコープ**: **完全個人専用（シングルユーザー・完全オフライン・外部DB＆ファイルI/Oゼロ）**

## 1. 確定した基本方針（3大コア設計）

複雑化やバグの原因となる「外部データベース（SQLite）」「デバイス間通信同期」「CSVファイルの読み書き・権限管理」をすべて削ぎ落とし、以下のシンプルな構成に統一しています。

1. **アプリ内静的辞書バンドル（`StaticLexicon`）**:
   * 新音韻体系（6母音＋4二重母音＋16子音）に基づく基本語幹、文法機能語（全9軌道格・代名詞・疑問詞・星軌数詞0〜9）、および主要派生語・複合語をKotlinの不変コレクションとしてアプリバイナリに直結内包します。
   * ※旧版の200語幹は白紙化（リセット）し、シャレイア語・キプソル語準拠の流麗な語彙として再構築中。

2. **決定論的造語 ➔ 整合性検証 ➔ 静的コード昇格パイプライン**:
   * **自動造語**: 辞書にない未知語は、新音韻規則および決定論的ハッシュ（FNV-1a ＋ 同音衝突回避ソルト）により、再現性のある2音節語幹（`C1 V1 C2 V2 C3` 等、末尾は `l, r, n, m, s`）を即座に生成します。
   * **検証と昇格**: 自動生成された未知語を正式採用したい場合は、画面上のインスペクターで「4大整合性検証」を実行し、ワンクリックで **Kotlinコード定義（`LexiconEntry`）** をクリップボードへコピーしてソースコードへ貼り付け・ビルドするだけで恒久的に辞書へ統合されます。

3. **独自文字「Nebulith Script（星辰筆記文字）」と公式転写体系（NRS）**:
   * 象形文字を排し、シャレイア文字・キプソル文字のようにペンの柔らかなストローク（円弧・ループ・アーチ・結節点）で構成される**抽象表音文字**を採用。
   * PCキーボードやソースコードで快適かつ1対1の可逆変換ができる**「公式ラテン文字転写体系（NRS）」**を完全定義。

## 2. 言語・文字仕様の要点

* **音韻体系**: 
  * 6大単母音（`a, e, i, o, u` ＋ 第6天体母音 **`y` [y]**）
  * 4大公転二重母音（`ai, ei, au, oi`）
  * 16主星子音（`m, n, l, r`, `s, z, c [ʃ], j [ʒ]`, `f, v, h, w`, `p, t, k, b, d, g`）＋ 原初軸 `'` [ʔ]
  * 音節末（Coda）は流音・鼻音・歯擦音 `l, r, n, m, s` の5種に限定（心地よい余韻の創出）。

* **8大語形成規則**:
  1. **`-or`**: 動作主・行為者（`dokil` 教育 → `dokilor` 教師）
  2. **`-is`**: 専門職・学者（`sufan` 数理 → `sufanis` 数学者）
  3. **`-ek`**: 道具・装置（`sufan` 計算 → `sufanek` 計算機）
  4. **`-ad`**: 場所・施設（`dokil` 教育 → `dokilad` 学校）
  5. **`-um`**: 学問・体系（`sylim` 星 → `sylimum` 天文学）
  6. **`-at`**: 被行為者・結果物（`kreas` 創造 → `kreasat` 作品）
  7. **`A + o + B`**: 連星複合語・縮約結合（`syli(m)` + `o` + `kura(n)` → `sylokuran` 星時計）
  8. **`ku- / ar- / mi- / ko- / re-`**: 反転・上位・縮小・共同・反復接頭辞（`kubonas` 醜）

* **統語論（天体軌道格・VSO）**:
  * 動詞を文頭（恒星）に置き、9つの軌道格パーティクル（主格 `el`, 対格 `ia`, 与格 `al`, 属格 `en`, 処格 `uo`, 具格 `de`, 向格 `to`, 奪格 `va`, 共格 `ku`）で名詞句を配置。

* **独自文字「Nebulith Script」と手記レンダラー**:
  * 共通ベースライン（$Y=200$）を持つ自立型グリフ。Pure Kotlin による **TrueTypeフォント（`.ttf`）直接出力** に完全対応。
  * Compose Canvas により、天文学者野帳（Astronomer Notebook）の手書きインク・罫線かすれ画像（`.png`）を出力。
