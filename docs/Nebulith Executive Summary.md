**対象バージョン**: 要件定義・設計仕様書 v17.0 / **マスター辞書データ v22.0（全16カテゴリー・計1,008語幹収録／目標1,000語大台達成 100.8%／純粋星辰語版・地球言語借用ゼロ）**

## 1. 確定した基本方針（3大コア設計）

複雑化やバグの原因となる「外部データベース（SQLite）」「デバイス間通信同期」「CSVファイルの読み書き・権限管理」をすべて削ぎ落とし、以下のシンプルな構成に統一しています。

1. **アプリ内静的辞書バンドル（`StaticLexicon`）**:
   * 新音韻体系（6母音＋4二重母音＋16子音）に基づく基本語幹、文法機能語（全9軌道格・代名詞・軌道数詞0〜10）、および主要派生語・複合語をKotlinの不変コレクションとしてアプリバイナリに直結内包します。
   * **v22.0マスター辞書**: 全16カテゴリーにわたる計1,008語幹（目標1,000語マイルストーン達成・進捗率100.8%）を完全収録。英語やラテン語等の地球言語からの借用・引きずりを完全に排除し、星辰の流麗な無標ソノリティ（母音、`l, r, n, m, s`）を基調としつつ、瞬発・硬質・制動のニュアンスに応じて破裂音（`-t, -k, -p, -d`）や摩擦音（`-f, -v`）の有標Codaを有機的に共存させた純粋架空言語体系。

2. **決定論的造語 ➔ 整合性検証 ➔ 静的コード昇格パイプライン**:
   * **自動造語**: 辞書にない未知語は、新音韻規則および決定論的ハッシュ（FNV-1a ＋ 同音衝突回避ソルト）により、再現性のある語幹（`C1 V1 C2 V2 C3` 等）を即座に生成します。
   * **検証と昇格**: 自動生成された未知語を正式採用したい場合は、画面上のインスペクターで「4大整合性検証」を実行し、ワンクリックで **Kotlinコード定義（`LexiconEntry`）** をクリップボードへコピーしてソースコードへ貼り付け・ビルドするだけで恒久的に辞書へ統合されます。

3. **独自文字「Nebulith Script（星辰筆記文字）」と公式転写体系（NRS）**:
   * 象形文字を排し、ペンの滑らかなストローク（円弧・ループ・アーチ・結節点）で構成される**抽象表音文字**を採用。
   * PCキーボードやソースコードで快適かつ1対1の可逆変換ができる**「公式ラテン文字転写体系（NRS）」**を完全定義。

## 2. 言語・文字仕様の要点

* **音韻体系**: 
  * 6大単母音（`a, e, i, o, u` ＋ 第6天体母音 **`y` [y]**）
  * 4大公転二重母音（`ai, ei, au, oi`）
  * 16主星子音（`m, n, l, r`, `s, z, c [ʃ], j [ʒ]`, `f, v, h, w`, `p, t, k, b, d, g`）＋ 原初軸 `'` [ʔ]
  * **柔剛調和の音節末（Coda）**: 流麗な余韻を生む開音節および `l, r, n, m, s` を基底としつつ、硬質性・瞬発性・確固たる概念（`suf` 計算, `tor` しかし, `kiv` ビット, `jyt` 結節, `krap` 昆虫, `jylot` 盟約, `torp` 衝突 等）において破裂音・摩擦音の語末を美しく活用。

* **3次元方向副詞体系（総合的副詞 `-u` ＆ 分析的格表現 `to`）**:
  * 総合的副詞: 方位・空間語幹 ＋ `-u` による一語での方向表現（`kymdenu` 西へ, `faldenu` 東へ, `novdenu` 北へ, `tuldenu` 南へ, `vorasu` 前へ, `pasonu` 後ろへ, `lerinu` 左へ, `parinu` 右へ, `celosu` 上へ, `talosu` 下へ, `silinu` 内へ, `folanu` 外へ 等）
  * 分析的格表現: 第7軌道向格 `to` ＋ 名詞句（`to kymden` 西方へ向かって）

* **全16カテゴリー分類体系（全1,008語・v22.0 Grand Milestone 1000）**:
  1. `天体・宇宙力学・光` (80語)
  2. `数理・幾何・計測` (48語)
  3. `情報・計算機・通信` (66語)
  4. `生命・生体・医療` (80語)
  5. `自然地形・地質・鉱物` (46語)
  6. `気象・大気・水域` (58語)
  7. `植物・生態・農耕` (48語)
  8. `動物・生物種・共生` (45語)
  9. `統治・社会・法・共同体` (70語)
  10. `経済・交易・工芸・労働` (46語)
  11. `建築・都市・住空間` (46語)
  12. `食・飲料・調理・食具` (50語)
  13. `衣飾・携行具・日常品` (50語)
  14. `精神・哲学・感情・芸術` (76語)
  15. `性質・状態・色彩・感触` (80語)
  16. `動作・動態・時空・方向副詞` (119語)

* **派生接尾辞マスターシステム**:
  1. **`-as`**: 日常的行為者・実務者（`ner` 食 ➔ `neras` 配膳者）
  2. **`-or`**: 専門職・知識人・医師（`suf` 計算 ➔ `sufor` プログラマー、`daris` 治癒 ➔ `darisor` 医師）
  3. **`-is`**: 学術研究者・探求者（`vyran` 真理 ➔ `vyranis` 哲学者、`sufis` 数理学者）
  4. **`-el`**: 道具・器具・機械・客体（`kiras` 創る/書く ➔ `kirel` ペン、`ner` 食 ➔ `nerel` 料理）
  5. **`-ar` / `-an`**: 場所・施設・空間（`dom` 部屋 ➔ `domar` 家、`daris` 治癒 ➔ `darisar` 病院）
  6. **`-il`**: 指小辞・愛称・親愛（`vel` 木 ➔ `velil` 若木・薬草）
  7. **`-om`**: 集合体・領域・世界（`dom` 部屋 ➔ `domom` 都市、`vyr` 星 ➔ `vyrom` 星座）
  8. **`-i` / `-u`**: 形容詞化（`-i`）／副詞化（`-u`）（`falun` 光 ➔ `faluni` 明るい、`tyk` 拍 ➔ `tyku` 直ちに）

* **統語論（天体軌道格・VSO）**:
  * 動詞を文頭（恒星）に置き、9つの軌道格パーティクル（主格 `el`, 対格 `ia`, 与格 `al`, 属格 `en`, 処格 `uo`, 具格 `de`, 向格 `to`, 奪格 `va`, 共格 `ku`）で名詞句を配置。

* **独自文字「Nebulith Script」とフォント**:
  * 全64グリフ（アルファベット26字、数字10字、基本約物）を収録した TrueTypeフォント `fonts/Nebulith-Regular.ttf` が完成・同梱。
