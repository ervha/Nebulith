* **節マーカー**: **`lu ... le`**（関係節）、**`ke ... le`**（名詞節）、**`rel`**（関係代名詞）
* **文末観想法助詞**: **`ka`**（疑問）、**`ze`**（確証）、**`na`**（伝聞）、**`lo`**（希求・祈願）
* **10大星軌数詞（0〜9）**:
  * `0` **`nil`** [nil]（虚無・空環）
  * `1` **`un`** [un]（単星・光柱）
  * `2` **`du`** [du]（連星・双対）
  * `3` **`tra`** [tra]（三ツ星・三葉）
  * `4` **`tes`** [tes]（四界・惑星環）
  * `5` **`pen`** [pen]（五芒星・調和）
  * `6` **`sel`** [sel]（彗星・流尾）
  * `7` **`syr`** [syr]（七星・昴天蓋）

## 2. 新・基本語幹策定フレームワーク（再構築中）

旧版のラテン語借用風200語幹は白紙化（リセット）されました。
新体系では、以下の**シャレイア・キプソル的音節規則**に従い、流麗で心地よい語幹を順次策定・登録します。

### 語幹構造規則（Syllable Conformance）
1. **長さ**: 2音節（4〜5文字基準）。
2. **骨格**: `C1 V1 C2 V2 (C3)` または `C1 V1V2 C2 V2 (C3)`。
3. **母音**: 6単母音（`a, e, i, o, u, y`）および 4二重母音（`ai, ei, au, oi`）。
4. **末子音（Coda）**: 語末子音は `l, r, n, m, s` の5種に厳密限定。
