### 1.3 接続詞・関係節・星軌数詞（0〜9）

* **等位・従属接続詞**: **`se`**（そして / and）、**`ve`**（または / or）、**`ma`**（しかし / but）、**`si`**（もし〜なら / if）、**`ze`**（だから / then, so）、**`da`**（なぜなら / because）、**`te`**（〜だけれども / although）
* **節マーカー**: **`lu ... le`**（関係節）、**`ke ... le`**（名詞節）、**`rel`**（関係代名詞）
* **文末観想法助詞**: **`ka`**（疑問）、**`ze`**（確証）、**`na`**（伝聞）、**`lo`**（希求・祈願）
* **10大星軌数詞（0〜9）**:
  * `0` **`zo`** [zo]（無・虚空）
  * `1` **`ko`** [ko]（単星）
  * `2` **`so`** [so]（連星）
  * `3` **`to`** [to]（三曜）
  * `4` **`no`** [no]（四極）
  * `5` **`ho`** [ho]（五芒）
  * `6` **`mo`** [mo]（六華）
  * `7` **`yo`** [jo]（七曜）
  * `8` **`ro`** [ɾo]（無尽）
  * `9` **`wo`** [wo]（極限）
  * 位取り連結方式: 例 `10` = `kozo`, `100` = `kozozo`, `2026` = `sozosomo`、小数点 = `pi`、序数 = `+i`

## 2. 新・基本語幹策定フレームワーク（再構築中）

旧版のラテン語借用風200語幹は白紙化（リセット）されました。
新体系では、以下の**シャレイア・キプソル的音節規則**に従い、流麗で心地よい語幹を順次策定・登録します。

### 語幹構造規則（Syllable Conformance）
1. **長さ**: 2音節（4〜5文字基準）。
2. **骨格**: `C1 V1 C2 V2 (C3)` または `C1 V1V2 C2 V2 (C3)`。
3. **母音**: 6単母音（`a, e, i, o, u, y`）および 4二重母音（`ai, ei, au, oi`）。
4. **末子音（Coda）**: 語末子音は `l, r, n, m, s` の5種に厳密限定。

*(※ 新しい基本語幹群は、ユーザーとの語感選定を経て、順次本セクションへ正式収録されます)*
