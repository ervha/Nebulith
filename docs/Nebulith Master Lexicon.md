## 1. 文法機能語・代名詞・軌道数詞マスターテーブル（Grammar & Numbers）

公式ラテン文字転写体系（NRS: Nebulith Romanization System）に準拠。すべての語末は母音またはソノリティ共鳴音（`l, r, n, m, s`）で統一。

### 1.1 天体軌道格パーティクル（Orbital Case Particles：全9格）
動詞（恒星）の周りを巡る9つの軌道格標識。

| 格コード | NRS転写 | 発音 (IPA) | 日本語訳・文法機能 | 英語対応 |
| :--- | :--- | :--- | :--- | :--- |
| `NOM` (第1軌道：主格) | **`el`** | [el] | 〜は、〜が（動作主・主題） | [Subject / Agent] |
| `ACC` (第2軌道：対格) | **`ia`** | [ja] | 〜を、〜である（対象・コピュラ補語） | [Object / Patient / Complement] |
| `DAT` (第3軌道：与格) | **`al`** | [al] | 〜に、〜へ（受け手・相手） | to, for [Recipient] |
| `GEN` (第4軌道：属格) | **`en`** | [en] | 〜の（所有・所属：`A en B` ＝ BのA） | of, 's [Genitive] |
| `LOC` (第5軌道：処格) | **`uo`** | [wo] | 〜で、〜において（場所・時点） | at, in, on [Location / Time] |

| `COM` (第9軌道：共格) | **`ku`** | [ku] | 〜と共に、〜と（同伴・共同） | with, together with [Companion] |

### 1.3 接続詞・時制小詞・否定・10大星軌数詞（0〜9）

* **接続詞**: **`se`**（そして / and）、**`ve`**（または / or）、**`ma`**（しかし / but）、**`si`**（もし / if）、**`ze`**（だから / so）、**`da`**（なぜなら / because）、**`te`**（〜だけれども / though）
* **時制・相小詞（動詞前置）**: **`fe`**（過去）、**`se`**（未来）、**`di`**（進行中）
* **否定小詞**: **`ne`**（通常否定：〜ない）、**`nila`**（根源的否定：全き無、欠片も存在しない）
* **10大星軌数詞（0〜9）**:
  * `0` **`nil`** [nil]（虚無・空環）
  * `1` **`un`** [un]（単星・光柱）
  * `2` **`du`** [du]（連星・双対）
  * `3` **`tra`** [tra]（三ツ星・三葉）
  * `4` **`tes`** [tes]（四界・惑星環）
  * `5` **`pen`** [pen]（五芒星・調和）
  * `6` **`sel`** [sel]（彗星・流尾）
  * `7` **`syr`** [syr]（七星・昴天蓋）
  * `8` **`ora`** [ora]（双極環・共鳴）
  * `9` **`nura`** [nura]（銀河渦・極限）
  * 位取り連結方式: 例 `10` = `un-nil`, `100` = `un-nil-nil`, `2026` = `du-nil-du-sel`、序数 = 接尾辞 `+i`（例: `uni` 第1の, `dui` 第2の）

## 2. 接尾辞体系：役割・機能・領域の自然な分化（Suffix Framework）

英語の `-er` と `-or` の違いのように、語末によって行為者の立場、専門性、道具、場所、小さな愛称へと有機的に分化する。

| 接尾辞 | 機能・役割 | 英語相当 | 象徴イメージ | 具体例 |
| :---: | :--- | :---: | :--- | :--- |
| **`-as`** | **日常的な行為者・親しみある人** | **`-er`** | その行為をする自然な人 | `cival` (歌う) → **`civalas`** (歌い手 / singer)<br>`laran` (歩く) → **`laranas`** (旅人 / traveler) |
| **`-or`** | **専門職・天職・導師・医師・官** | **`-or`** | 資格・技術・導きの立場 | `daris` (水/癒し) → **`darisor`** (医師・治癒師 / doctor)<br>`vyrel` (観測) → **`vyrelor`** (観測官 / astronomer)<br>`sufor` (プログラマー / engineer) |
| **`-is`** | **学者・探求者・賢人・求道者** | **`-ist`** | 真理や道を生涯探求する者 | `vyran` (理) → **`vyranis`** (哲学者 / philosopher)<br>`fenor` (言葉) → **`fenoris`** (言語学者 / linguist) |
| **`-el`** | **道具・器具・機械・装置** | **`-ment / -er`** | その行為・現象を媒介する器 | `suf` (計算) → **`sufel`** (PC・計算機)<br>`vyrel` (見る) → **`vyrelel`** (望遠鏡)<br>`soras` (記憶) → **`sorasel`** (手記・ノート) |
| **`-ar` / `-an`** | **場所・施設・空間・集まる処** | **`-arium / -ory`** | 行為や人々が集積する場所 | `vyrelar` (天文台), `darisar` (診療所・病院)<br>`sorasan` (記録院・書庫・DB), `nerar` (カフェ・食堂) |
| **`-il`** | **愛称・縮小（〜の欠片・小さな〜）**| **`-let / -ie`** | 小さく愛おしい存在 | `vyr` (星) → **`vyril`** (星の子、小さな星屑)<br>`vel` (木) → **`velil`** (若木、小さな草花) |
| **`-i`** | **形容詞化（修飾語）** | **`-ic / -ous`** | 性質・状態をもつ | `falun` (光) → **`faluni`** (明るい、輝かしい)<br>`meli` (愛しき、親愛なる) |
| **`-u`** | **副詞化（様態・状況）** | **`-ly`** | どのように行うか | `falun` (光) → **`falunu`** (明るく、光り輝いて)<br>`havel` (時) → **`havelu`** (絶え間なく、時を越えて) |
| **`-om`** | **状態・世界・領域（〜界）** | **`-dom / -ness`** | 概念が広がる全体圏 | `cielom` (天蓋世界), `velom` (森林・樹海)<br>`domom` (都市・街), `tolom` (インターネット・通信網) |

## 4. 現代日常＆手記の総合例文集（Specimen Sentences）

> **① 現代IT・プログラミングの風景**  
> **`Sufor el sufan ia sufom uo sufel.`**  
> （スフォール・エル・スファン・ヤ・スフォム・ウォ・スフェル）  
> 訳：「エンジニアがPCでプログラムを書いている。」

> **② スマホでメッセージを送る日常**  
> **`Tolan an ia tolas al tu de tolel.`**  
> （トラン・アン・ヤ・トラス・アル・トゥ・デ・トレル）  
> 訳：「私はスマホであなたにメッセージを送る。」

> **③ カフェで雨を見つめる静かな時間**  
> **`Darlen el toren uo domom, se vyrel an uo nerar.`**  
> （ダルレン・エル・トーレン・ウォ・ドモム、セ・ヴュレル・アン・ウォ・ネラール）  
> 訳：「街に雨が降り、私はカフェの中からそれを見つめている。」

> **④ 森の中の自然と医師の慈しみ**  
> **`Darisor el serin ia velil uo velom.`**  
> （ダリソル・エル・セリン・ヤ・ヴェリル・ウォ・ヴェロム）  
> 訳：「医師が、森に芽吹いた小さな薬草にそっと触れる。」

> **⑤ 天文学者の手記ノート**  
> **`Sorasel uo fenor en vyris ia soras an.`**  
> （ソラセル・ウォ・フェノール・エン・ヴュリス・ヤ・ソラス・アン）  
> 訳：「手記ノートの中に、私は星々の言葉を書き留める。」
