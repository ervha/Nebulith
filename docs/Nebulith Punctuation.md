## 収録記号

| 種類 | 入力文字 | 意匠 |
|---|---|---|
| 疑問・感嘆 | `? ？` / `! ！` | 開いた探索軌道と核 / 放射光芒と基底核 |
| 句点・読点 | `. ． 。` / `, ， 、` | 終止核 / 彗星尾 |
| 接続・小休止 | `: ：` / `; ；` | 上下の連星 / 連星と彗星尾 |
| 省略 | `… ⋯` | 三つの終止核 |
| 丸括弧 | `( （` / `) ）` | 対向する抱擁軌道 |
| 角括弧 | `[ ［` / `] ］` | 中央核を持つ観測枠 |
| 波括弧 | `{ ｛` / `} ｝` | 対向する双極境界 |
| 引用符 | `‘ ’` / `“ ”` / `" ＂` | 方向を持つ浮遊核 / 二重核 / 中立の二重核 |
| 和文の引用符 | `「 『` / `」 』` | 左右の二重引用核に対応 |
| 接続・区切り | `- －` / `— ―` / `/ ／` | 短い架橋 / 長い連星架橋 / 斜交軌道 |
| 演算・注記 | `+ ＋` / `= ＝` / `×` / `÷` / `* ＊` | 連結核 / 双軌道 / 交差軌道 / 分離軌道 / 六方星印 |
| 音素キャリア | `'` | 既存の声門キャリア。引用符とは別字形 |

全角・和文の別表記はcmapで同じグリフへ対応させる。元のテキストやUnicodeを自動置換する機能ではない。全角記号も同じ字幅になり、和文全角送りを保証するものではない。

`?`は疑問文末のkaを自動で付けるものではなく、文法は引き続き言語仕様書に従う。フォントの追加によって新しい文法・演算規則を定義したわけではない。

## 維持した字形と検証

既存v2.1の65グリフは輪郭・字幅を全件維持した。`.`の終止核、`,`の彗星尾、`:`と`-`、音素キャリア`'`も既存の字形を使う。追加分は線幅と軌道環・星辰核のモチーフを揃えた。

TrueTypeテーブル、Unicode対応、全記号の描画輪郭、元の字形・字幅、規範コーパス全体の収録文字、再ビルドのバイト再現性をテストする。フォントは2.5、コーパスは23.3として別々に版管理する。

字形の独自性は個別審査中。旧65グリフから87グリフへ監査対象を拡張したことを [標準監査手順書の版改訂](../audit/docs/Nebulith%20Standard%20Audit%20Report.md) に記録し、過去の報告・旧フォントは書き換えず保存した。

## 再生成

リポジトリルートで実行する。

```powershell
.\.venv-audit\Scripts\python.exe tools/build_font.py
.\.venv-audit\Scripts\python.exe tools/sync_web_fonts.py
.\.venv-audit\Scripts\python.exe -m unittest discover -s tests -v
```

追加字形と入力別表記の定義は `tools/font_symbols.py`。新しい字形へ変更する際は `data/audit/glyph_reviews.json` の対象・フォントハッシュも更新し、以前の判定を引き継がず再評価する。

v2.3ではU/u・J/jの4字形を変更した。記号27種・別表記の対応はv2.2から維持している。

v2.4ではA/a・S/sを曲線主体に調整した。記号の輪郭・入力別表記・字幅は維持する。筆流・文字列の確認用に `fonts/handwriting.html` を追加した。

v2.5では記号27種の角・線端に軽微な丸みと傾きを加えた。意味・慣用骨格・別表記の対応・送り幅は維持する。
